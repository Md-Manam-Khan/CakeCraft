# 🍰 CakeCraft

A full-stack bakery ordering and cake customization web application built as a **Software Development Project**.

CakeCraft is a web-based bakery platform designed to make the process of **discovering, customizing, ordering, and tracking cakes** simple, interactive, and user-friendly.

The project is currently under active development and will gradually evolve from a frontend prototype into a complete full-stack bakery management and ordering platform.

---

## 🚧 Current Status

**Development in Progress**

The current version contains:

* Initial frontend landing page
* Customer information form

* Git/GitHub integration

More features will be added progressively as development continues.

## 🎯 Project Goal

The goal of CakeCraft is to build a **complete bakery ordering and management platform** rather than a simple static website.

The application will gradually evolve through multiple development stages, including frontend development, interactive functionality, backend implementation, database integration, authentication, ordering, and administrative management.
